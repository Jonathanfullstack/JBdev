# Plano do blog — 12 artigos

Público: dono de pequena empresa, sem tecniquês. Cada artigo mira uma palavra de cauda longa e aponta para **uma** página de serviço.
Os 6 primeiros serão escritos por completo (1.200–1.800 palavras). Os 6 últimos entram como rascunho (`draft: true`, fora do sitemap) com título, meta, estrutura e links.

Regras para todos: `title` ≤ 60 caracteres, meta description ≤ 155, H2/H3 em forma de pergunta, exemplo prático, FAQ no fim (FAQPage), 2–4 links internos, CTA para `/contato`, dados estruturados `Article` + `BreadcrumbList`. Nenhuma estatística sem fonte: onde precisar, `[FONTE NECESSÁRIA]`. Nenhum preço inventado: faixas de valor ficam como `[R$ 0.000]` até você passar os números.

Categorias (do mockup): **Sites**, **Sistemas**, **Automação & IA**, **Apps**.
