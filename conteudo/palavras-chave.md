# Plano de palavras-chave — JB DEV

Região principal: **Indaiatuba/SP** (sede). Secundárias, já citadas no site atual: Campinas, Itu, Salto, Sorocaba. Atendimento remoto em todo o Brasil.

> **Volumes de busca:** não inventei números. Antes de publicar, valide cada termo no Google Keyword Planner (ou Search Console depois de 4–8 semanas no ar) e ajuste as prioridades. A coluna "Prioridade" abaixo é uma estimativa qualitativa: intenção comercial × chance de ranquear para um negócio local novo.

**Regra de canibalização:** cada página tem **uma** palavra principal. As secundárias aparecem no texto, mas nunca como palavra principal de outra página.

## 5. Versão em inglês

O site novo terá `/en/...`. O foco de ranqueamento é **pt-BR** (clientes locais). As páginas em inglês recebem `hreflang`, metadata traduzida e conteúdo equivalente, mas não terão pesquisa de palavras-chave própria. Os 12 artigos do blog ficam só em pt-BR, a menos que você peça a tradução.
